Learning Objectives
01
Data Collection & Preprocessing
Collect your own data

Pull speed, current and vibration off a live motor, and turn a messy stream into a table you can model.

02
Exploratory Data Analysis
Find out what's in it

Plot it, spot the outlier, work out which sensor is lying — before trusting any of it.

03
Feature Engineering
Build the features

Turn a raw vibration trace into numbers a model can use: RMS, peaks, frequency bands.

04
Model Development & Evaluation
Train and test honestly

Fit the model, then split the data properly so the accuracy is real and not leaked.

05
Real-world Problem Solving
Handle the messy case

The load changes, the motor heats up, the sensor drifts. Deal with it.

06
Algorithm Comparison
Pick the right model

Run several on the same data and find out why the fancy one doesn't always win.

AIMX Software — AI for ML Experiments

A no-code platform covering the whole ML workflow. Students explore data, train models and deploy one to the hardware without writing a line of code. Two tiers.

Watch Demo
Included with MLK
AIMX Standard

Everything a first course needs. Students run the complete workflow on data from their own kit — explore it, train classification, regression and clustering models, compare them, and deploy one back to the hardware.

Add-on Purchase
AIMX Advanced

For project and research work. A much wider model library, and it accepts any CSV — so a final-year project isn't limited to the kit's own data.

AIMX Standard AIMX Advanced
Model library A curated set across classification, regression and clustering — enough to teach the trade-offs properly Substantially wider, including modern boosting and Gaussian-process methods
Input data Data from your ML Kit Your ML Kit, plus any external CSV
Best for Undergraduate lab courses and first ML modules Final-year projects, dissertations and research groups
