Machine Learning Kit (MLK)

A compact, sensor-rich data generator for hands-on AI education. Officially licensed from IIT Bombay.

  • 12 live signals: speed, current, power, voltage and 3-axis vibration
  • PMDC motor with quadrature encoder, 3-axis MEMS accelerometer (±2 g), ARM Cortex-M4F at 84 MHz
  • Hot-swap magnetic load disks; USB 2.0 to a Windows PC with timestamped CSV export
  • AIMX Standard included (6 experiments, 25 ML models); AIMX Advanced and CARIMO ML Notebooks as add-ons

DC Motor Kit (DCMK)

A real plant on a bench for hands-on control education. Officially licensed from IIT Bombay.

  • PI/PID Python software included: speed and position control, 7 experiments, no MATLAB® needed
  • MPC and Fuzzy Logic as optional add-ons, in Web App or Simulink® editions
  • USB 2.0 to a Windows PC with timestamped CSV logging; 1-year hardware warranty
